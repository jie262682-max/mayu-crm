一、产品概述

1.1 产品定位

码域CRM 是一套面向中小企业的一体化经营管理平台，覆盖「市场获客 → 销售跟进 → 合同回款 → 协同审批 → 资产管理」全流程。系统包含三大业务中心：

中心覆盖能力说明
CRM 客户管理线索、客户、联系人、跟进、公海、商机、产品、合同、回款、统计报表销售全链路，线索到回款闭环
OA 协同办公审批流引擎（或签/会签/条件分支）、待办、我的申请、请假、消息通知、短信合同/回款/请假/资产报废自动走审批
EAM 资产管理资产台账、领用/退回/借出/归还、报修、报废审批、盘点、月度折旧固定资产全生命周期

1.2 三端入口

端地址 / 方式适用场景

三端账号通用、数据实时同步。PCH5小程序 标记表示该功能在哪些端可用。

二、快速上手

2.1 PC 端登录 PC

步骤：① 打开 https://crm.hefeicode.com → ② 输入用户名、密码 → ③ 点击「登 录」→ 进入系统主页（默认打开用户管理）。

左侧为功能菜单（按角色动态显示），顶部右侧 铃铛图标显示未读消息数（每 30 秒自动刷新），点击进入消息中心。

2.2 手机 H5 登录 H5

步骤：① 手机浏览器打开 https://crm.hefeicode.com/m/ → ② 输入账号密码 → ③ 登录后底部导航：客户 / 待办 / 资产 / 我的。
建议「添加到主屏幕」，使用体验接近原生 App。

2.3 微信小程序 小程序

步骤：① 微信开发者工具 → 导入项目 → 目录选择 freecrm-app/dist/build/mp-weixin → ② AppID 使用测试号或自有 AppID → ③ 详情-本地设置勾选「不校验合法域名」→ ④ 编译运行。正式发布需在小程序管理后台配置 request 合法域名（https://crm.hefeicode.com）。

三、线索管理

线索是未确认的潜在客户信息，来源于电话咨询、官网表单、展会名片等 6 类渠道。

3.1 新建线索 PC

路径：CRM 客户管理 → 线索管理 → 「新建线索」→ 填写线索名称（必填）、联系人、手机、邮箱、来源、行业 → 保存。

3.2 线索跟进 PC

路径：线索列表 → 「跟进」→ 查看时间线 → 在「写跟进」区填写内容 → 提交。

3.3 转化为客户 PC

路径：线索列表 → 「转化」→ 确认。

转化后系统自动：① 创建客户（线索信息带入）；② 创建联系人（线索联系人转入）；③ 迁移全部跟进记录到新客户名下。线索标记为已转化，不可重复转化。

四、客户管理

4.1 客户查重与合并 PC

查重：客户管理 → 「查重」→ 输入名称或手机号 → 列出疑似重复客户。
合并：查重结果中点「设为保留」选择保留客户 → 点其他客户的「并入保留客户」→ 确认。被并客户的联系人、跟进、商机、合同全部迁移到保留客户后删除。Excel 导入时同名客户自动跳过。

4.2 客户资料上传（多文件）PC H5/小程序

PC：客户列表 → 「资料」→ 「选择文件（可多选）」→ 点「上传 N 个文件」。支持列表查看、下载、删除。
手机：客户详情 → 「客户资料」区 → 「上传资料（可多选）」→ 选择文件自动上传；点击文件名下载。
单个文件不超过 20MB。下载权限：团队成员可下载，非团队成员被拒绝。

4.3 跟进与附件 PC H5

PC：客户列表 → 「跟进」→ 写跟进区可点「📎 添加附件（可多选）」→ 提交跟进时附件一起上传，附件挂在该条跟进记录下，时间线中显示 📎 标签，点击直接下载。
H5：客户详情 → 「写跟进」选类型（电话/拜访/微信）→ 填内容 → 可选「下次联系日期」→ 📎 加附件 → 提交。
每次跟进自动刷新客户「最后联系时间」；填了下次联系日期会同步到客户字段。

4.4 团队数据权限（三级）

级别能力
负责人 OWNER全部操作，含转移、删除
可写 WRITE编辑、跟进、上传资料、录合同回款
只读 READ仅查看和下载资料

商机、合同、回款权限跟随所属客户的团队设置。PC 客户列表「团队」入口可添加/移除成员并设置级别。

4.5 公海机制 PC

放入公海：客户列表 → 「放公海」→ 负责人清空、团队解散，客户进入公海池。
领取：公海客户 → 「领取」→ 领取人成为新负责人。
已成交客户、锁定客户不能放入公海。

4.6 公海自动回收

系统每小时自动检查（规则在「系统管理 → 系统设置」配置）：

  • 掉保回收：超过 N 天（默认 30）未跟进的客户自动入公海；
  • 超期回收：创建超过 N 天（默认 90）未成交的客户自动入公海；
  • 回收后系统向原负责人发送站内信通知；已成交 / 已锁定客户不回收。

五、联系人管理

路径：客户管理 → 客户列表 → 「联系人」→ 「新增联系人」→ 填写姓名、手机、职务、决策角色（决策者/影响者/使用者/教练）、邮箱。

客户详情页（H5）同样展示联系人。转化线索时联系人自动带入。

六、商机管理

6.1 阶段组与阶段 PC

商机按「阶段组」推进（内置：标准销售流程 / 大客户流程）。每个阶段有名称、赢率（百分比）、顺序。可在商机管理页维护阶段组。

6.2 创建与推进商机 PC

创建：商机管理 → 「新建商机」→ 选客户、阶段组、预计金额、预计成交日期。
推进：商机列表 → 「推进」→ 选择下一阶段。阶段按顺序推进。

6.3 赢单 / 输单

结束：商机列表 → 「结束」→ 选赢单或输单。
商机赢单后，所属客户自动标记为「已成交」。

七、产品与合同

7.1 产品库 PC

路径：产品管理 → 新建产品（名称、编号、分类、价格、单位：件/套/年/次、状态上架/下架）。支持多级产品分类。

7.2 合同台账 PC

新建合同：合同管理 → 「新建合同」→ 填合同名、客户、总金额、下单日期。合同编号自动生成（HT+日期+序号）。

合同状态机：草稿(0) → 审批中(1) → 已通过(2) / 已驳回(3)。仅草稿可编辑；已进入审批的合同锁定。

7.3 合同产品明细行 PC

路径：合同列表 → 「明细」→ 选择产品（自动带出单价）→ 输入数量 → 「添加」→ 实时显示小计与合计 → 「保存明细」。
草稿状态可编辑明细；进入审批后明细只读。

八、回款管理

8.1 回款计划 PC

路径：合同列表 → 「计划」→ 填期数、回款日、金额 → 「加计划」。

8.2 录入回款 PC

前置条件：合同必须「已通过」审批。合同列表 → 「回款」→ 填回款日期、金额、方式（对公转账/现金/微信/支付宝/其他）→ 保存。

回款保存后自动进入回款审批流；审批通过后合同「已回款」自动累计。驳回的回款不累计。

硬性拦截：① 未通过审批的合同不能录回款；② 回款累计不得超过合同总额（超额直接拒绝并回滚）。

九、审批流

9.1 我的待办 PC H5

PC：OA 协同办公 → 我的待办 → 列表显示每级待审任务（含业务单摘要：合同号/请假事由等）。
H5：底部「待办」tab → 点任务卡片 → 查看业务单详情 + 审批轨迹（每级审批人/意见/时间）→ 填意见 → 「同意」或「驳回」。

9.2 审批规则（业务自动触发）

业务触发时机审批通过后
合同审批合同「提审」合同 → 已通过，可录回款
回款审批录入回款单合同已回款累计
请假审批发起请假请假单 → 已通过
资产报废资产「报废」资产 → 报废状态

9.3 撤回 PC

路径：OA → 我的申请 → 找到进行中的流程 → 「撤回」（仅申请人本人可撤，流程结束后不可撤）。

9.4 流程定义（管理员）PC

路径：OA → 流程定义 → 编辑/新建 → 按顺序添加节点：
  • 审批节点：选审批人（多选）+ 签署方式：或签（任一人通过即过级）或 会签（全部通过才过级，多人同时收到待办即并行）；
  • 条件节点：按业务金额路由，如 amount >= 50000 跳到「总监会签」，否则直达「总经理」。可用变量：amount（合同/回款金额）、contractAmount、days（请假天数）。
示例：合同审批 = 销售经理(或签) → 金额分支（≥5万 → 总监会签(2人) → 总经理；<5万 → 直达总经理）。未配置流程时：合同走负责人人工审核，回款自动通过。

十、EAM 资产管理

10.1 资产台账 PC

新建：EAM → 资产台账 → 「新增资产」→ 填名称、分类、型号、序列号、购置日期/金额、折旧年限、部门、位置。资产编号自动生成（ZC+日期）。

资产四种状态：闲置 / 在用 / 维修 / 报废。

10.2 领用 / 退回 / 借出 / 归还 PC H5/小程序

PC：资产台账行内操作 → 「领用」（输入领用人ID，留空=自己）、「退回」、「借出」（输入借用人ID）。
H5：「资产」tab → 闲置资产卡片上「我要领用」一键领取；详情页可「领用 / 退回 / 报修」。

每次操作自动记录变更：类型、从谁到谁、原因、时间，资产详情「变更历史」完整可查。

10.3 报修与维修完成 PC

「报修」（填原因）→ 状态转「维修」→ 维修完成后「修完」→ 回到「闲置」。

10.4 报废（走审批）PC

「报废」→ 填原因 → 若配置了报废流程自动进入审批；审批通过后资产置为「报废」。

10.5 资产盘点 PC

① 「创建盘点单」选范围（全部 / 按部门）→ 系统快照资产账面状态；② 打开盘点单「明细」逐项实盘：选实际状态（闲置/在用/维修/盘亏）→「提交实盘」，不一致自动标记差异；③ 「仅差异」可只看差异项；④ 全部盘完后「完成盘点」，单据显示总数/差异数。

10.6 月度折旧

直线法，残值率 5%：月折旧 =（购置金额 × 95%）÷（年限 × 12）。每月 1 日凌晨自动生成上月折旧（幂等，重复执行不重复生成）；净值降到残值后自动停提。折旧记录页可按月查询、可「手动生成上月折旧」补算。

十一、消息通知

11.1 站内信 PC H5

自动触发场景：① 审批待办（发给审批人）；② 审批结果（通过/驳回/撤回，发给申请人）；③ 公海回收（发给原负责人）。

PC：顶栏铃铛显示未读数 → 点击进入「我的消息」→ 可单条已读 / 全部已读，审批待办消息可「去处理」直达。
H5：「我的」→「我的消息」。

11.2 阿里云短信（管理员配置）PC

路径：系统管理 → 系统设置 → 「阿里云短信」页签 → 填写：
  • AccessKeyId / AccessKeySecret（阿里云 RAM 账号密钥，Secret 保存后脱敏显示）
  • 短信签名（如：合肥市码域科技）
  • 模板 Code（如 SMS_xxxxxxxx）
  • 启用开关 + 「审批待办短信通知」开关
测试：输入手机号 → 「发送测试」→ 下方「发送记录」查看成功/失败及原因。配置即时生效，无需重启。
短信模板需在阿里云控制台申请；验证码类模板仅适用验证码场景，审批通知请申请通知类模板（变量名需与系统配置一致，可在数据库 sys_config 的 sms.var.name 调整）。

十三、Excel 导入导出 PC

路径：客户管理 → 「导入/导出」下拉：
  • 下载导入模板：含表头与示例行（示例行导入时自动跳过）；

十四、系统管理 PC

14.1 用户管理

新建用户（用户名+初始密码必填，选部门）；编辑资料；删除用户。修改密码：编辑用户时填写新密码。

14.2 角色管理与菜单授权

① 角色管理 → 「新建角色」（名称/编码）；② 点「菜单授权」→ 树形勾选该角色可见的页面与按钮级权限（如「线索转化」「合同审核」）→ 保存。③ 该角色用户重新登录后生效。
勾选树中的灰色小项（按钮）是操作权限，不显示在菜单里；父级半选表示部分子项已授权。

14.3 菜单管理

维护页面菜单（目录/页面/按钮三级）：路径、组件、权限码、图标、排序、是否侧栏可见。一般无需改动。

14.4 部门管理

树形部门，支持加子部门、编辑、删除（有子部门需先删子部门）。部门用于用户归属与资产使用部门。

14.5 系统设置

  • 公海回收规则：掉保天数 / 超期天数；
  • 阿里云短信：见第十一章。

14.6 操作日志 / 登录日志

操作日志记录关键动作（保存/删除/审批/导入导出/上传等）：操作人、模块、动作、参数（点行展开）、成功失败、耗时、IP。登录日志记录每次登录成功/失败与 IP。

十五、常见问题 FAQ

问题解答
登录后菜单是空的？该角色未被授权任何菜单，找管理员在「角色管理 → 菜单授权」勾选后重新登录。
看不到某个客户/合同？数据权限所致：只有客户团队成员可见。让负责人在「团队」中把你加为可写或只读。
提示「没有操作权限：xxx」？缺少对应按钮权限，管理员在角色授权树中勾选对应按钮项。
合同提交后没有进入待办？检查 OA → 流程定义中该业务是否有「启用」状态的流程；未配置时合同由负责人在列表直接「通过/驳回」。
录回款提示「合同未审核通过」？正常拦截：先完成合同审批。
录回款提示「超过合同总额」？正常拦截：已回款 + 本次 > 合同总额。检查是否有重复录入。
会签节点一人通过后流程没动？会签需全部审批人通过才推进，查看待办是否还有同节点其他人的任务。
手机端资产列表空白？该角色无 EAM 权限，管理员为其角色勾选「EAM 资产管理」相关菜单。
短信测试失败？在「系统设置 → 发送记录」查看具体错误：常见为 AK 无权限、签名/模板不一致、手机号无效（无效号不产生计费）。
Excel 导入全部被跳过？与现有客户重名或首列为空；模板中的示例行也会被跳过，属正常。
网页刷新后白屏/功能异常？强制刷新（Ctrl+F5）清缓存；H5 直跳子页面需刷新一次，从入口点击导航则正常。

16.3 业务规则速查

  • 线索转化 = 自动建客户 + 联系人 + 迁移跟进
  • 团队三级权限：负责人 / 可写 / 只读；商机合同回款随客户
  • 公海：放入即清负责人+解散团队；成交/锁定不可入池；掉保30天/超期90天自动回收（可配）
  • 合同：0草稿→1审批中→2通过/3驳回；仅通过可录回款；明细行合计联动
  • 回款：审批通过才累计；累计 ≤ 合同总额
  • 商机赢单 → 客户自动成交
  • 审批：或签任一过、会签全过、条件按金额路由；驳回即终止并通知申请人
  • 资产：闲置→领用/借出→在用→退回→闲置；报修→维修→修完→闲置；报废走审批
  • 折旧：直线法 5% 残值，每月 1 日自动，提完即停
  • 文件：单文件 ≤ 20MB；UUID 存储原名入库；越权下载被拒

16.4 安全建议

  • 上线后立即修改 admin 初始密码，并按最小权限原则分配角色
  • 阿里云 AccessKey 只授予短信发送权限（AliyunDysmsFullFullAccess 最小化为发送动作）
  • 定期在「操作日志」审计关键操作；MySQL 定期备份（含 crm_/oa_/eam_/sys_ 全部业务表）
