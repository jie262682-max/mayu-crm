# 码域CRM 自主部署指南（从零到上线）

> 面向首次部署的运维/开发人员。按顺序执行即可完成一套完整部署（PC + 手机 H5 + 小程序构建产物 + HTTPS）。
> 已在 CentOS 7 / Ubuntu 均适用的通用命令为准，个别差异已标注。

---

## 0. 你会得到什么

| 组件 | 默认端口 | 说明 |
|------|---------|------|
| 后端 API | 48100 | Spring Boot fat jar，systemd 常驻 |
| PC 管理端 | 80/443（nginx） | 静态站点 + /api 反代 |
| 手机 H5 | 同域名 /m/ 路径 | 同一 nginx |
| 微信小程序 | — | 构建产物，微信开发者工具上传 |
| MySQL | 3306 | 库名自定（本文用 mycrm） |
| Redis | 6379 | Sa-Token 会话（可选，无则内存会话） |

---

## 1. 环境准备

| 软件 | 版本要求 | 安装方式（CentOS 示例） |
|------|---------|------------------------|
| JDK | 8 | `yum install -y java-1.8.0-openjdk java-1.8.0-openjdk-devel` |
| Maven | 3.6+ | 官网解压或 `yum install maven` |
| MySQL | 5.7 / 8.0 | 自行安装或宝塔面板 |
| Redis | 任意稳定版 | `yum install redis && systemctl enable --now redis`（可选） |
| Node.js | 18+ | 官网 / nvm |
| pnpm | 8+ | `npm i -g pnpm` |
| nginx | 1.20+ | `yum install nginx` 或宝塔 |

> Windows 本地开发同样适用（JDK8 + Maven + Node），构建产物一致。

## 2. 获取代码并构建

```bash
# 2.1 拿到代码（拷贝仓库或压缩包），路径建议纯英文
mkdir -p /opt/maoyu && cd /opt/maoyu
# scp / git clone 你的仓库地址 freecrm
cd freecrm

# 2.2 后端构建（fat jar 约 78MB，首次拉依赖较慢）
mvn clean package -DskipTests
# 产物：freecrm-server/target/freecrm-server-0.1.0-SNAPSHOT.jar

# 2.3 PC 前端
cd freecrm-web && pnpm install && pnpm build
# 产物：dist/          ← 回到上级：cd ..

# 2.4 移动端 H5
cd freecrm-app && pnpm install && pnpm build:h5
# 产物：dist/build/h5  ← cd ..

# 2.5（可选）小程序
cd freecrm-app && pnpm build:mp-weixin
# 产物：dist/build/mp-weixin
```

> pnpm 11+ 若提示构建脚本被忽略：确认 `pnpm-workspace.yaml` 的 `allowBuilds`（仓库已带）。

## 3. 数据库初始化

```bash
mysql -u root -p
```
```sql
CREATE DATABASE mycrm DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_general_ci;
-- 建议专库专号：
CREATE USER 'crm'@'localhost' IDENTIFIED BY '你的强密码';
GRANT ALL ON mycrm.* TO 'crm'@'localhost';
FLUSH PRIVILEGES;
```

按顺序导入（脚本自带 `CREATE DATABASE freecrm` 的话先删掉那两行或用 sed 换库名）：

```bash
# 若库名不是 freecrm：sed -i 's/`freecrm`/`mycrm`/g; /CREATE DATABASE/d; /^USE /d' sql/*.sql
cd sql
for f in freecrm-schema freecrm-crm freecrm-m3 freecrm-oa freecrm-eam \
         freecrm-m11 freecrm-m15-menu freecrm-eam-menu freecrm-m16; do
  mysql -u root -p --default-character-set=utf8mb4 mycrm < $f.sql
done
# 演示数据（可选，含 8 测试账号与全链路样例数据）
mysql -u root -p --default-character-set=utf8mb4 mycrm < freecrm-demo-data.sql
```

> 管理员账号 admin/admin123 由后端**首次启动**自动创建；演示账号见 docs/demo-accounts.md。

## 4. 后端部署

### 4.1 目录规划
```
/opt/maoyu/app/
├── freecrm-server.jar       ← freecrm-server/target/*.jar 改名放这
├── application.yml          ← 外部配置（覆盖 jar 内，生产必放）
└── uploads/customer/        ← 客户附件存储（自动创建，需可写）
/opt/maoyu/web/dist_pc/      ← PC 构建产物
/opt/maoyu/web/dist_h5/      ← H5 构建产物
```

### 4.2 外部 application.yml（按实际改库号密码/域名）
```yaml
server:
  port: 48100

spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/mycrm?useSSL=false&serverTimezone=Asia/Shanghai&characterEncoding=utf8&allowPublicKeyRetrieval=true
    username: crm
    password: 你的强密码
    driver-class-name: com.mysql.cj.jdbc.Driver
  redis:                      # 没装 Redis 可整段删掉（会话退化为内存，重启需重新登录）
    host: 127.0.0.1
    port: 6379
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: Asia/Shanghai

mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: deleted
      logic-delete-value: 1
      logic-not-delete-value: 0
  configuration:
    map-underscore-to-camel-case: true

sa-token:
  token-name: Authorization
  timeout: 2592000
  token-style: uuid
  is-read-header: true
  is-read-cookie: false

logging:
  level:
    com.freecrm: info
  file:
    name: /opt/maoyu/app/freecrm.log

file:
  upload-dir: /opt/maoyu/app/uploads/customer
```

### 4.3 systemd 常驻
```bash
cat > /etc/systemd/system/freecrm.service <<'EOF'
[Unit]
Description=MaoyuCRM Server
After=network.target mysqld.service

[Service]
Type=simple
WorkingDirectory=/opt/maoyu/app
ExecStart=/usr/bin/java -Xms256m -Xmx512m -jar freecrm-server.jar
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
EOF
systemctl daemon-reload && systemctl enable --now freecrm
sleep 30 && systemctl is-active freecrm   # 应显示 active

# 健康检查（首次启动会自动建 admin 账号与菜单）
curl -s -X POST http://127.0.0.1:48100/api/auth/login \
  -H 'Content-Type: application/json' -d '{"username":"admin","password":"admin123"}'
# 期望返回 {"code":0,...,"token":"..."}
```

## 5. nginx 与 HTTPS

### 5.1 站点配置（宝塔用户：网站→添加站点后替换 conf；裸机：写入 /etc/nginx/conf.d/mycrm.conf）

```nginx
# 80：ACME 验证 + 跳转 HTTPS（证书签好前先注释 return 301 那行）
server {
    listen 80;
    server_name crm.你的域名.com;
    location ^~ /.well-known/acme-challenge/ { root /var/www/html; }
    location / { return 301 https://$host$request_uri; }
}

server {
    listen 443 ssl http2;
    server_name crm.你的域名.com;
    index index.html;
    root /opt/maoyu/web/dist_pc;

    ssl_certificate     /etc/nginx/ssl/crm.fullchain.cer;      # 按实际路径
    ssl_certificate_key /etc/nginx/ssl/crm.key;
    ssl_protocols TLSv1.2 TLSv1.3;

    # 带哈希的静态资源长缓存
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    # PC（Vue history 路由回退）
    location / {
        add_header Cache-Control "no-cache";
        try_files $uri $uri/ /index.html;
    }
    # 移动端 H5（部署于 /m/）
    location /m/assets/ {
        alias /opt/maoyu/web/dist_h5/assets/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    location /m/ {
        alias /opt/maoyu/web/dist_h5/;
        add_header Cache-Control "no-cache";
        try_files $uri $uri/ /m/index.html;
    }
    # 后端 API 反代（Host 改写：避免域名含下划线时 Tomcat 拒绝）
    location /api/ {
        proxy_pass http://127.0.0.1:48100;
        proxy_set_header Host 127.0.0.1:48100;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        client_max_body_size 20m;      # 附件上传上限
    }

    access_log /var/log/nginx/mycrm.log;
}
```
```bash
nginx -t && systemctl reload nginx
```

### 5.2 免费证书（acme.sh，自动续期）
```bash
curl https://get.acme.sh | sh -s email=you@example.com
~/.acme.sh/acme.sh --issue --webroot /var/www/html -d crm.你的域名.com
mkdir -p /etc/nginx/ssl
~/.acme.sh/acme.sh --install-cert -d crm.你的域名.com \
  --fullchain-file /etc/nginx/ssl/crm.fullchain.cer \
  --key-file       /etc/nginx/ssl/crm.key \
  --reloadcmd "systemctl reload nginx"
```

> ⚠️ 域名不要含下划线 `_`（如 oa_crm），所有 CA 拒签；用连字符。

## 6. 移动端注意事项

- **H5**：生产构建已按「同域 /api 反代」处理，无需改代码；只要 nginx 按上文配置即可。
- **真机联调（非同域时）**：改 `freecrm-app/src/api/request.js` 的 `PROD_BASE` 为 `http://电脑局域网IP:48100` 后重新 build。
- **微信小程序**：
  1. `pnpm build:mp-weixin` → 微信开发者工具导入 `dist/build/mp-weixin`
  2. manifest 的 mp-weixin appid 换成你的小程序 AppID
  3. 开发阶段勾选「不校验合法域名」
  4. 发布前在小程序管理后台「开发管理→服务器域名」添加 `https://crm.你的域名.com`
- **APP（安卓/iOS）**：HBuilderX 导入 `freecrm-app` 目录 → 发行→云打包；`PROD_BASE` 必须是手机可达的域名。

## 7. 上线后配置（管理员登录后）

| 事项 | 位置 |
|------|------|
| 改 admin 密码 | 系统管理 → 用户管理 → 编辑 admin |

## 8. 日常运维

```bash
systemctl restart freecrm                    # 重启后端
journalctl -u freecrm -n 100                 # 启动日志
tail -f /opt/maoyu/app/freecrm.log           # 业务日志
nginx -t && systemctl reload nginx           # 改 nginx 后
```

**发版三步**（代码更新后）：
1. 后端：`mvn clean package -DskipTests` → 替换 `/opt/maoyu/app/freecrm-server.jar` → `systemctl restart freecrm`
2. PC：`cd freecrm-web && pnpm build` → dist 覆盖 `/opt/maoyu/web/dist_pc/`
3. H5：`cd freecrm-app && pnpm build:h5` → 覆盖 `/opt/maoyu/web/dist_h5/`

**数据备份**：
```bash
mysqldump -u root -p --default-character-set=utf8mb4 mycrm | gzip > /backup/mycrm-$(date +%F).sql.gz
# 建议加入 cron 每日执行；同时备份 /opt/maoyu/app/uploads/（客户附件）
```

## 9. 故障排查速查

| 现象 | 原因/处理 |
|------|-----------|
| 启动失败 `Port 48100 was already in use` | 改 application.yml 端口或停占用进程 |
| 登录返回 500 连接拒绝 | MySQL 地址/账号错；看 freecrm.log |
| 页面能开但接口全 404 | nginx 未配 /api 反代，或 proxy_pass 写错 |
| 上传附件报错目录创建失败 | `file.upload-dir` 路径不存在或无写权限（WorkingDirectory 决定相对路径基准，建议配绝对路径） |
| 登录后菜单空白 | 全新库正常现象见 §3 已导入菜单脚本；角色未授权菜单则去角色管理勾选 |
| 附件下载 404 | jar 重启后 uploads 目录被移动；确认 upload-dir 指向固定绝对路径 |
| 小程序真机请求失败 | PROD_BASE 未改/非 HTTPS/不在同一网络 |
| 短信发送失败 | 系统设置→发送记录看错误信息（AK 权限/签名模板不匹配/余额） |
| 折旧没生成 | 每月 1 日自动跑上月；可在 EAM→折旧记录手动生成补算 |
| 旧数据升级后菜单缺失 | 重新执行 sql/freecrm-m15-menu.sql 与 freecrm-eam-menu.sql（幂等） |

## 10. 安全清单（上线必查）

- [ ] 修改 admin 初始密码；禁用/删除演示账号（zhang3 等）
- [ ] MySQL 只监听 127.0.0.1，业务账号仅授权本库
- [ ] 后端 48100 不对公网开放（仅 nginx 本机反代）；防火墙/安全组只放 80/443
- [ ] HTTPS 强制（80→301）
- [ ] 阿里云 AccessKey 单独 RAM 子账号，只授短信发送权限
- [ ] 定时备份 MySQL + uploads 目录，并演练恢复
